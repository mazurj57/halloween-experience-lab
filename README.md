# Halloween Experience Lab

An interactive B1 English lesson that uses Halloween experiences to practise the Present Perfect and Past Simple.

## Live lesson

https://mazurj57.github.io/halloween-experience-lab/

## Included activities

- illustrated vocabulary cards with browser speech
- past participle and Present Perfect form practice
- meaning matching and personalized experience sentences
- contextual dialogue completion
- grammar error repair
- final speaking-plan builder and exit check

The website is built with plain HTML, CSS, and JavaScript and requires no installation.
